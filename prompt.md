Crée un **artefact visuel interactif et animé** permettant de comparer les écrans de trois smartphones :

1. **Google Pixel 11 Pro Fold**
2. **Samsung Galaxy Z Fold** — utilise le modèle le plus récent disponible et indique clairement sa référence exacte.
3. **Google Pixel 7 Pro**, utilisé comme point de comparaison avec un smartphone classique non pliable.

### Objectif

Je veux comprendre **visuellement et immédiatement les différences de taille, de proportions et de surface d’affichage** entre les trois appareils, et pas seulement lire leurs caractéristiques dans un tableau.

### Données

Recherche et vérifie les caractéristiques les plus récentes disponibles avant de construire la comparaison. Si certaines caractéristiques du Pixel 11 Pro Fold ne sont pas officiellement confirmées, indique clairement les données comme **rumeurs / estimations** et ne les présente pas comme des spécifications officielles.

Compare au minimum :

* diagonale de l’écran en pouces ;
* dimensions physiques de la zone d’affichage ;
* résolution ;
* ratio d’écran ;
* densité de pixels (ppi) ;
* luminosité maximale ;
* taux de rafraîchissement ;
* technologie de dalle ;
* taille de l’écran externe et de l’écran interne pour les modèles pliables.

### Visualisation principale

Crée une représentation **à l’échelle réelle relative** des trois écrans.

Je veux pouvoir voir les téléphones :

* côte à côte ;
* superposés avec transparence ;
* centrés les uns sur les autres pour comparer leurs dimensions ;
* avec une option permettant de passer de l’écran externe à l’écran interne des modèles Fold.

Ajoute une animation fluide où :

1. le **Pixel 7 Pro apparaît en premier** comme référence ;
2. le Pixel 11 Pro Fold vient se superposer dessus ;
3. son écran se **déplie progressivement** ;
4. le Samsung Galaxy Z Fold apparaît ensuite ;
5. les trois écrans s’alignent et se superposent ;
6. des repères visuels indiquent les différences de largeur, hauteur, diagonale et surface.

### Animation

Utilise des transitions fluides de type :

* morphing ;
* scale ;
* fade ;
* ouverture de charnière pour les Fold ;
* superposition semi-transparente.

L’animation doit permettre de comprendre intuitivement le passage :

**Pixel 7 Pro → smartphone pliable fermé → smartphone pliable ouvert.**

Ajoute un bouton **« Rejouer l’animation »**.

### Interactions

Ajoute des contrôles permettant de sélectionner :

**[Pixel 7 Pro] [Pixel 11 Pro Fold] [Samsung Galaxy Z Fold]**

ainsi que :

**[Côte à côte] [Superposition] [Écran fermé] [Écran ouvert]**

Lorsque je survole ou sélectionne un appareil, affiche ses dimensions et caractéristiques principales.

### Comparaison de surface

Calcule également la différence de **surface d’écran en cm² et en pourcentage**.

Par exemple, affiche visuellement des informations comme :

**« L’écran ouvert du Pixel Fold offre environ XX % de surface supplémentaire par rapport au Pixel 7 Pro. »**

Fais le même calcul pour le Samsung Fold.

### Mise en situation

Ajoute une deuxième visualisation montrant la quantité de contenu visible sur chaque écran avec exactement la même interface fictive :

* une page web ;
* une vidéo 16:9 ;
* une application avec une liste ;
* deux applications côte à côte en multitâche.

Cela doit montrer non seulement quel écran est plus grand, mais **ce que cette différence change réellement à l’usage**.

### Design

Adopte une esthétique premium inspirée des présentations de produits Google et Samsung :

* fond sombre élégant ;
* smartphones réalistes mais épurés ;
* bordures et coins arrondis fidèles aux appareils ;
* typographie moderne ;
* animations à 60 fps si possible ;
* interface responsive ;
* aucun élément visuel inutile.

Évite un simple tableau statique : **la visualisation des dimensions doit être l’élément central de l’expérience.**

### Conclusion

Termine par un résumé très court indiquant :

* quel appareil possède le plus grand écran ;
* lequel est le plus large une fois ouvert ;
* lequel est le plus proche du format du Pixel 7 Pro lorsqu’il est fermé ;
* lequel offre le plus de surface utile pour le multitâche.

Ajoute également les **sources utilisées pour les dimensions et caractéristiques techniques**.
